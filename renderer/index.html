SEB PrintWindow Capture New
When Safe Exam Browser is detected, capture automatically switches to PrintWindow(PW_RENDERFULLCONTENT) — captures the SEB window directly even after affinity is bypassed. Works when BitBlt is blocked.
Stealth & SEB Bypass
👁️
Stealth Overlay Stealth
HaimuAi runs as a WS_EX_LAYERED window with WDA_EXCLUDEFROMCAPTURE cleared. It's invisible to screen recorders, DWM capture, DXGI duplication, and OBS.
💉
Native Affinity Bypass NewAuto
Automatically detects Safe Exam Browser, Respondus, LockDown Browser, Proctorio, ExamSoft, ProctorU. Injects code inside the target process via QueueUserAPC(LoadLibraryW) to call SetWindowDisplayAffinity(WDA_NONE). Re-checks every 800ms. Fully automatic — no interaction needed.
AutomaticCtrl+Shift+F force re-inject
🔧
AffHook.dll Auto-Compile
On first run, automatically compiles a native C DLL using Visual Studio cl, GCC, or TCC (downloads TCC if no compiler found). The DLL runs inside SEB, sweeping all windows every 1.2s for 6 minutes. More effective than shellcode.
👻
Ghost Mode
Makes HaimuAi nearly invisible — only faint text is visible. Hover over any element to temporarily reveal it. Perfect when you need maximum stealth and someone is watching your screen.
Alt+G
🔒
Always Active Mode
Clicking HaimuAi never steals focus from the exam window. WS_EX_NOACTIVATE is set — no WM_ACTIVATE events, no window-switch detection by exam browsers.
Ctrl+Shift+A
⚡
Immortal Guardian
A self-healing process tree respawns HaimuAi within 3–8 seconds if it's killed. Runs via Windows Task Scheduler for maximum persistence across reboots.
📌
30ms Topmost Watchdog
Re-asserts HWND_TOPMOST every 30ms to stay above the exam browser's own raise-window watchdog. Uses WinEventHook to re-show within 500ms if an external monitor hides the window.

Pro Tips
🔑
Add 3+ Gemini API keys in Settings → API Keys. HaimuAi rotates them automatically when one hits the daily quota — you never get blocked mid-exam.
📸
Use Alt+A (Answer) instead of manually screenshotting. It captures + sends to AI + answers in one keypress — the fastest way during timed exams.
🛡️
SEB bypass is fully automatic — just launch HaimuAi before (or after) starting SEB. The watchdog detects it within 2 seconds and starts injecting automatically. No buttons needed.
👁️
Always Active mode (Ctrl+Shift+A) prevents any window-switch alerts. Enable it before the exam starts so HaimuAi can receive your clicks without the exam browser detecting focus loss.
🎧
For oral/video interviews: Use Listen mode (Alt+L) to capture everything the interviewer says. Press Stop & Answer — AI answers all their questions from the audio transcript.
⌨️
Auto-Type is your safest bet for coding answers — AI types the solution directly into the exam editor. Combine with Always Active so focus never leaves the exam window.
💡
Ghost Mode (Alt+G) makes HaimuAi nearly invisible if someone looks at your screen. Hover over text to read it, move away and it fades. Use it in physical exam rooms.
🔧
If the DLL compilation fails (no compiler), HaimuAi automatically falls back to shellcode injection — still effective, just slightly slower at clearing newly-protected windows.
